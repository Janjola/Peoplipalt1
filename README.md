# Dot Loading — Phone-friendly APK build

This project creates a simple offline Android app with a black background and animated blue dots.

## Build the APK using GitHub Actions (no PC required)
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root, preserving folders.
3. Open the repository's **Actions** tab.
4. Select **Build Dot Loading APK** and tap **Run workflow**.
5. When it finishes successfully, open that run and download the `DotLoading-debug-apk` artifact.
6. Extract the downloaded artifact ZIP to get `app-debug.apk`.
7. Share `app-debug.apk` via WhatsApp or Telegram. Recipients may need to allow installing unknown apps for the app they use to open it.

This is a debug APK for personal sharing, not a Play Store release.
